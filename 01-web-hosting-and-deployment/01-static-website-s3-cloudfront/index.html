AWS PROJECT 01

Static Website Hosting on AWS

A secure static website stored in Amazon S3 and delivered globally using Amazon CloudFront.

View Architecture View GitHub

PROJECT OVERVIEW

What this project demonstrates

This project demonstrates how to host a static website using Amazon S3 while using Amazon CloudFront for secure HTTPS delivery, caching, and improved global performance.

ARCHITECTURE

Amazon S3

Stores the HTML, CSS, and JavaScript files

AWS SERVICES

Services used in this project

Amazon S3

Stores the website files, including HTML, CSS, JavaScript, and images.

Amazon CloudFront

Delivers the website through a global content delivery network with HTTPS and caching.

Origin Access Control

Allows CloudFront to access the private S3 bucket without exposing the bucket directly to the internet.

PROJECT GOALS

What I will complete

✓ Create a responsive static website
✓ Store website files in Amazon S3
✓ Keep the S3 bucket private
✓ Configure CloudFront Origin Access Control
✓ Deliver the website using HTTPS
✓ Configure a custom error page
✓ Document cost and cleanup steps
