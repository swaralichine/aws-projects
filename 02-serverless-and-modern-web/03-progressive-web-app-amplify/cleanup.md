# Cleanup Guide

Delete the following AWS resources after completing the project.

## AWS Amplify

1. Open AWS Console
2. Navigate to AWS Amplify
3. Select the application
4. Choose **App Settings**
5. Delete the application

---

## GitHub

Optional:

Delete the repository if no longer required.

---

## Local Project

No cleanup is required.

The project can be rebuilt at any time using:

```bash
npm install
npm run build
```

---

After deleting the Amplify application:

- Storage: $0
- Hosting: $0
